# 실험 이력

> 공개용 합성 기록입니다. 모델명·수치는 실제 값이 아닙니다.

기간: 약 5주

## CT 파이프라인

CT 이미지는 세로 4,000px의 긴 단면이고, 결함은 폭 4~15px의 기공(porosity)이다.
원본을 통째로 줄이면 가로 5px 결함이 1.6px로 뭉개지므로, 학습과 추론 모두
1280 타일(SAHI)로 해상도를 맞췄다.

| 모델 | 평가셋 | F1 | 비고 |
|---|---|---|---|
| seg-base | 홀드아웃 (새 셀) | 0.512 | 초기 세그멘테이션 |
| seg-tile | 홀드아웃 (새 셀) | 0.471 | 타일 학습 모델. 홀드아웃에서 붕괴 |
| **배포 챔피언** seg-v2 | 동분포 val 8,400장 | 0.903 | conf 0.12. 전 셀을 학습해 홀드아웃 측정 불가 |
| 같은 설정 · 셀 단위 분할 학습 | 홀드아웃 새 셀 6개 · 9,800장 | 0.641 | 챔피언과 분할 방식만 다른 별도 모델 |

**0.903과 0.641은 서로 다른 모델 · 평가셋의 값이다.** 같은 모델의 성능이 떨어진 것이
아니라, 분할 방식만 바꾼 두 모델로 새 셀에 대한 일반화 수준을 따로 잰 것이다.

지표도 바꿨다. mask mAP50으로는 seg-base보다 낮아 기각했던 seg-v2가, 이미지 단위
PASS/REJECT F1로 다시 재자 1위였다(240장 subset, seg-base 0.512 대비 0.738).

seg-tile 모델은 동분포에서는 좋아 보였으나 홀드아웃에서 seg-base보다 낮았다.
동분포 점수만 봤다면 잘못된 모델을 배포할 뻔했다. 이것이 홀드아웃 평가를
분리해 둔 이유다.

SAHI 적용 시 각인·이음매 영역에 오탐이 군집으로 발생했다.
같은 셀을 plain(비타일) 조건으로 추론하면 해당 오탐은 0건이었다.
즉 오탐의 원인은 결함 자체가 아니라 타일 경계 처리에 있었다.

## EXT(외관) 파이프라인

지도학습 세그멘테이션으로는 점 결함 recall이 0.089에 그쳤다.
학습 데이터를 늘리는 대신 open-vocabulary detection + VLM 조합으로
전환했고, **학습 0회, 신규 라벨 0장**으로 점 recall 0.774를 얻었다(8.7배).

- Pollution F1: 0.962
- Damaged F1: 0.455 — 각인 숫자를 손상으로 오인하는 사례가 주 원인

주의: EXT 점 recall 0.774는 표본 120장 기준이며, 라벨을 작성한 사람과
평가를 수행한 사람이 동일하다. 독립 검증이 되어 있지 않다.

## CT와 EXT를 분리한 이유

CT와 RGB 데이터는 서로 다른 배터리 타입이고 셀 ID도 대응되지 않는다(unpaired).
하나의 멀티모달 모델로 묶으면 존재하지 않는 대응관계를 학습하게 되므로,
두 개의 독립 파이프라인으로 설계했다.
